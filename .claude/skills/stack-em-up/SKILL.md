---
name: stack-em-up
description: Route valid but out-of-scope code review feedback into a follow-up PR on top of the current stack. Use when evaluating or responding to pull request review comments.
---

When evaluating code review feedback, consider if the feedback fits within the scope of the current pr. If not, but the feedback is valid and should be addressed (refer to $yagni here to make sure it fits), then make a new pr on the top of the current stack that addresses the feedback and explain your move in the comment response to the code review comment.
