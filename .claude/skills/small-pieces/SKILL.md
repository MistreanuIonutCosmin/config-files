name: small-pieces
description: Break large changes into logical, reviewable stacked PRs with a bounded size. Use when planning or implementing work that may span more than one PR or exceed 500-750 lines of code.
---

Break changes into logical small pieces. No PR should exceed 500-750 loc. Stack your prs using gh stack. It's okay to first write a large change and then break it into smaller prs.
